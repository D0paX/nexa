# Quality Attributes

NEXA prioritizes:

1. security
2. correctness
3. maintainability
4. observability
5. reliability
6. performance
7. usability

## Security

Trust decisions must be defensible and resistant to straightforward spoofing.

## Correctness

Device and event state transitions must be deterministic and testable.

## Maintainability

Dependencies and abstractions must have clear ownership and reason to exist.

## Reliability

Transient network, database, or notification failures must not silently corrupt trust state.

## Performance

Scanning must be responsive without producing unnecessary network load.
