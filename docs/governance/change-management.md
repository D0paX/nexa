# Change Management

Changes are classified as:

## Editorial

Typos, formatting, clarification without technical effect.

## Feature

New behavior inside an existing architectural boundary.

## Architectural

Changes to module boundaries, data contracts, runtime, persistence, trust, security model, or external service architecture.

## Roadmap

Changes to major scope, phase order, or committed capability.

The more consequential the change, the stronger the required review and documentation.
