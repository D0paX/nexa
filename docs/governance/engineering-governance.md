# Engineering Governance

## Principles

- architecture is intentional
- security decisions are explicit
- quality gates are mandatory
- changes are reviewable
- documentation is part of delivery

## Ownership

The project owner and architecture process own major design decisions.

AI agents implement approved work and may propose alternatives, but cannot silently change project direction.

## Exceptions

An exception must document:

- what rule is being bypassed
- why
- duration
- risk
- owner
- remediation plan
