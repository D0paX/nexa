# Phase Gates

Each phase has four gates.

## Gate A — Ready

- requirements approved
- dependencies identified
- architecture decisions known
- security assumptions recorded
- test strategy defined

## Gate B — Implementation Complete

- planned implementation exists
- code is reviewed
- tests exist
- configuration is documented
- no known accidental scope expansion

## Gate C — Verification Complete

- automated validation passes
- integration validation passes where applicable
- security checks pass
- failure paths are tested
- agent verification report is complete

## Gate D — Accepted

- human review complete
- documentation synchronized
- risks addressed or explicitly accepted
- phase exit criteria met
- next phase authorized

A phase must never be marked complete solely from an AI agent's implementation summary.
