# UI Design Principles

The product UI applies a professional, restrained security-product aesthetic.

## Direction

- calm
- precise
- legible
- accessible
- information-dense where useful
- minimal decorative noise

## Explicitly prohibited

- cyberpunk visuals
- neon hacker aesthetics
- fake terminal interfaces used as decoration
- excessive glow
- gratuitous RGB styling
- emoji-based status indicators

The UI should look appropriate beside serious enterprise security products.
