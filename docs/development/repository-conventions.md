# Repository Conventions

## Root

`E:\NEXA` is the project/repository root in the current Windows development environment.

The repository must not contain an additional nested root folder named `nexa`.

## Planned top-level areas

The exact source tree is established by Phase 0 architecture work. Documentation should not invent implementation folders before they are justified.

## Generated content

Generated files should be distinguishable from source-controlled authoritative files where practical.
