# Coding Standards

## General

- prefer explicit, readable code
- use strong typing where practical
- validate external input
- raise meaningful errors
- keep functions focused
- avoid hidden global state
- make security-sensitive decisions explicit

## Python

- Python 3.12
- use Ruff for formatting/linting
- use a static type checker
- use structured logging
- do not use print statements as production logging

## Product content

No emojis in code strings intended for product output, logs, notifications, or UI.
