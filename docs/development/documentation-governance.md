# Documentation Governance

Documentation is treated as a maintained engineering artifact.

## Update triggers

Update documentation when a change affects:

- public behavior
- configuration
- interfaces
- architecture
- security assumptions
- operational procedures
- testing expectations
- user-facing workflows

## Avoiding drift

Prefer linking to a single source of truth rather than copying rules across many documents.

When a document becomes obsolete, mark it deprecated and link to its replacement before removing it.
