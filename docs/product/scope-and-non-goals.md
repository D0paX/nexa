# Scope and Non-Goals

## In scope

- local-network visibility
- device inventory and lifecycle
- cryptographic trust
- security-event generation
- mobile alerting
- reliability and security hardening
- later explainable behavioral detection
- carefully scoped defensive controls

## Not currently in scope

- web dashboard
- third-party network administration
- internet-wide scanning
- arbitrary offensive actions
- autonomous attacks
- bypassing router security controls
- credential harvesting

Future scope is governed by `docs/roadmap/roadmap-change-policy.md`.
