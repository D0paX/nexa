# Product Vision

NEXA provides a calm, trustworthy security experience for monitoring and verifying devices on a network controlled by the operator.

## Product promise

NEXA should make an important security state easy to answer:

> Which devices are present, which are trusted, and what happened when that trust changed?

## Product qualities

- reliable
- explainable
- privacy-conscious
- security-first
- operationally transparent
- visually professional
- maintainable

## Non-goals

NEXA is not:

- a general offensive security toolkit
- a credential theft platform
- a malware framework
- an unrestricted packet manipulation toolkit
- a replacement for enterprise network security infrastructure

Any future active network-control capability must remain authorization-bound and separately reviewed.
