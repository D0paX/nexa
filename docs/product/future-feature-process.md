# Future Feature Process

New capabilities should follow this lifecycle:

```text
Idea
 -> Feature proposal
 -> Scope/security review
 -> Architecture impact check
 -> ADR if needed
 -> Phase placement
 -> Implementation task
 -> Verification
 -> Documentation
 -> Release
```

A feature does not become roadmap scope merely because it was discussed.

This process is intended to keep NEXA future-proof without allowing uncontrolled scope growth.
