# Architecture Decision Records

Architecture Decision Records capture decisions that would otherwise be lost in code, chat, or memory.

## When to create an ADR

Create an ADR when a decision affects:

- architecture
- trust/security model
- cryptography
- external services
- persistence strategy
- major runtime/platform choices
- data contracts
- operational behavior
- future compatibility

## Naming

Use:

`ADR-NNN-short-title.md`

## Statuses

- Proposed
- Accepted
- Superseded
- Rejected
- Deprecated
